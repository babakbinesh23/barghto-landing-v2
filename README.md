# برقتو — طراحی لندینگ نسخه ۲

**Version 2 of Bargheto's Persian solar landing concept, focusing on staggered scroll motion and card transitions.**

> **وضعیت:** پروژه آزمایشی طراحی و توسعه رابط کاربری است؛ ادعای استقرار عملیاتی، کاربران واقعی یا صحت تجاری ارقام ندارد.

## معرفی

این مخزن یکی از طرح‌های وب‌سایت برقتو برای معرفی تجمیع برق خورشیدی و تجربه فارسی راست‌به‌چپ است. هر مخزن یک پیاده‌سازی/نسخه مستقل از رابط کاربری را نگهداری می‌کند.

## قابلیت‌ها

- چیدمان RTL و محاسبه‌گر درآمد فرضی
- Scroll Stagger در نمایش تدریجی المان‌ها
- Morph Cards برای حرکت و تغییر فرم کارت‌ها
- بخش‌های بررسی رایگان، FAQ و مقایسه مزایا

## ساختار مخزن

- `index.html` — صفحه
- `css/style.css` — استایل
- `js/script.js` — تعامل و محاسبات


## پیش‌نمایش آنلاین / Live demo

**[اجرای آنلاین barghto-landing-v2](https://babakbinesh23.github.io/barghto-landing-v2/)** — صفحه GitHub Pages در بررسی ۲۱ نوامبر ۲۰۲۶ باز شد. تست کامل تعاملات و ثبت واقعی فرم‌ها جزو این تأیید نیست.

## اجرای محلی

پیش‌نیاز: یک مرورگر جدید؛ برای مدیریت درست مسیرها بهتر است یک سرور استاتیک محلی داشته باشید. از ریشه مخزن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. به Build پیچیده یا Node.js نیازی نیست. تمایز با نسخه ۱، تأکید بر Scroll Stagger و Morph Cards است.

## نکات مهم

- این نسخه پروتوتایپ فرانت‌اند است؛ ثبت واقعی درخواست و صحت نرخ‌های مالی باید پیش از انتشار عملیاتی متصل و تأیید شود.
- ارسال اطلاعات شخصی، انتشار آمار عملکرد واقعی یا معرفی نرخ‌های بازار منوط به اتصال بک‌اند و تأیید داده‌هاست.
- قبل از بازنشر تصاویر، فونت‌ها و منابع بیرونی، مجوز استفاده را بررسی کنید.
- این مخزن بخشی از نمونه‌کارهای توسعه وب برقتو است و پروژه `smart-energy-city` مستقل از آن است.
